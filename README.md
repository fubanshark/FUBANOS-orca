# FUBAN OS

A personal productivity and self-development website.

## Technologies
- HTML
- CSS
- JavaScript
- Supabase

## Hosting
- Deploys to GitHub Pages using GitHub Actions when changes are pushed to `main`.
- In the repository settings, open **Pages** and set the source to **GitHub Actions**.
- The published site URL appears in the deployment workflow run.

## XP
- Focus sessions earn 1 XP per full minute after a 10-minute minimum, capped at 50 XP per session.
- Missions can be assigned a reward from 0 to 1000 XP and award it once when completed.
- Percentage missions award a proportional XP balance based on their current progress.
- XP is stored locally in the browser.
